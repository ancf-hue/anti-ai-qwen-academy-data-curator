## 📚 О проекте

**Anti-AI Qwen Academy: Data Curator** — это интерактивное веб-приложение для обучения специалистов по работе с данными в эпоху искусственного интеллекта. Курс разработан для библиотек, исследовательских центров и организаций, работающих с ИИ-контентом.

### 🎯 Основные задачи курса

- Подготовка чистых, этически сбалансированных датасетов
- Освоение методов аннотации и работы с метаданными
- Выявление и коррекция демографических и культурных смещений
- Обеспечение безопасности и юридической чистоты данных
- Документирование и версионирование датасетов

---

## ✨ Возможности

### 🎓 Обучение
- **10 интерактивных уроков** с практическими заданиями
- **Финальный экзамен** (10 вопросов) для получения сертификата
- **Двуязычный интерфейс** (русский/английский)
- **Голосовое сопровождение** (текст в речь)

### 🛠️ Инструменты практики
- **Конструктор датасетов** — создание мини-датасетов с параметрами качества
- **Симулятор аннотации** — практика разметки изображений
- **Детектор смещений** — визуализация и анализ демографических смещений
- **Генератор метаданных** — создание каталогов записей

### 📚 Библиотека знаний
- Роль куратора данных: миссия, зоны ответственности, KPI
- Инструментарий: Label Studio, CVAT, OpenCV, SQLite
- Навыки выпускника: hard skills и soft skills
- Где работают кураторы данных: от библиотек до AI-лабораторий

### 🏆 Сертификация
- Генерация уникального сертификата (QWEN-DATA-XXXXXX)
- Проверка подлинности по SHA-256
- Экспорт в JSON и Qwen-совместимых форматах
- Возможность распечатки сертификата
